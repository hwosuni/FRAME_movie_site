FRAME 영화 추천 웹사이트 - 시작하기

1. 압축을 푼 폴더에서 터미널을 엽니다.
2. 가상환경 생성:
   python -m venv .venv

3. 가상환경 실행 (Windows):
   .venv\Scripts\activate

4. Flask 설치:
   pip install -r requirements.txt

5. 실행:
   python app.py

6. 브라우저에서 접속:
   http://127.0.0.1:5000

현재 버전은 첫 화면과 취향 입력 폼만 구현되어 있습니다.
TMDB / OpenAI API는 다음 단계에서 연결합니다.
